## The different permissions available to standard and admin users

There are two license types available in BenefitFlow, **Standard Users** and **Admin Users**.  Below are the privileges that are available to each user type.

  

|  | **Standard Users** | **Admin User** |
| :--- | :--- | :--- |
| **General** |  |  |
| Run searches and export data | X | X |
| Use contact credits | X | X |
| Add and remove users |  | X |
| Set contact credit limits for users |  | X |
|  |  |  |
| **CRM Integrations** |  |  |
| Setup and manage CRM integrations |  | X |
| Manage CRM mapping table |  | X |
| Sync net-new contacts to CRM | X | X |
| Sync contact overwrites to CRM |  | X |
