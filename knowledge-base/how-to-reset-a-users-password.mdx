## A team admin can reset user's passwords via the team management page

<Note>
**Note**
 you must have an "admin" license to complete the below
</Note>

<Steps>
<Step>
Navigate to the team management page

	a. While logged into BenefitFlow click your name in the upper-righthand corner and click "team management"
</Step>
<Step>
Find the user in your user list and select the trash icon to remove them from BenefitFlow
<Frame>
![](/images/image-1.png)
</Frame>
</Step>
<Step>
Click the "add user" button and add the user back to your instance by inputting their name, email address, and role 
<Frame>
![](/images/image-2.png)
</Frame>
</Step>
<Step>
The user should get a new temporary password from onboarding@benefit-flow.com
</Step>
</Steps>
